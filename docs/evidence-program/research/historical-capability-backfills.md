Reviewed 8 October 2026. Five qualified, unadmitted source families; one bounded offline helper. This is a research review, not operational source admission, a published score dataset or an implementation of a universal capability curve.

## Scope and repository baseline

Both required source-priority and inventory files were rechecked at [bc00b609](https://github.com/mishakgg/pdoom-live/commit/bc00b609473c19c76869839598b63e1c8ace9ccc). The [catalog](../../../data/evidence-program/research/historical-capability-backfills.json) records 46 artifact references, 44 qualified findings, ten corrections, seven evidence holds and eight actions with seven focused follow-up prompts. Source inspection used bounded public primary evidence. No archive traversal, restricted archive access, agreement acceptance, output-corpus collection or deployment occurred.

Original runs, repeated reports, corrected assertions, rescoring of the same outputs, later reruns and benchmark dependence are separate relationships. Event, publication, generation, transport, preservation and retrieval dates have separate roles. Unknown first-publication/execution/capture dates remain unknown. Competition coverage does not recover all unsubmitted, rejected or unpublished dead ends.

## Priority order

1. **HC001**: Original, failed/invalid and changed planning evidence with explicit rescore versus rerun distinctions.
2. **HC002**: Small fixed structured artifact allows bounded offline parsing; public redistribution held.
3. **HC003**: Early recurring evidence and contemporary errors/corrections; facsimile and archive-access limitations explicit.

Rank is source utility, not capability, danger or p(doom). All five selected result-data families retain unresolved reuse rights. Public access and publisher custody do not prove historical immutability or redistribution permission.

## Bounded offline WMT08 reader

[read_wmt08_scores.py](../../../tools/evidence_program/read_wmt08_scores.py) is implemented as a standard-library offline review helper. It reads one supplied regular local file with a fixed allowlisted SHA-256; it has no network fetcher, archive crawler, scheduled collection, operational admission, canonical import or deployment route. A changed artifact needs a separately reviewed version, not a caller-selected pin.

The gzip is not bundled. No full extracted results or captured source pages/PDFs are included in this repository. Its reuse rights are unknown; the ACL publisher paper license does not propagate to the statmt score file. The [fixture notice](../../../tools/evidence_program/tests/fixtures/historical-backfills/NOTICE.md) describes self-authored synthetic-only CI.

### Local use and safety

Only run the real mode against the already-authorized local artifact. These commands do not acquire it. Keep resulting review JSON private while source redistribution rights remain unresolved.

```bash
python tools/evidence_program/read_wmt08_scores.py /path/to/authorized/local/wmt08-scores.gz
python tools/evidence_program/read_wmt08_scores.py /path/to/self-authored/synthetic.gz --synthetic
python -m unittest discover -s tools/evidence_program/tests -p "test_historical*.py" -v
```

An optional explicit transport observation can be supplied with `--observed-at` and `--http-last-modified`, in UTC ISO format ending in `Z`. The latter requires the former. It is an operator-supplied provenance assertion; the offline reader cannot verify the historical HTTP transaction. It must be tied to the exact source URL/pin and does not change unknown first-publication or execution dates. Synthetic mode rejects real transport provenance and has null source URLs, dates and WMT identities. Local file mtime and gzip header mtime are never used as publication evidence.

Hard limits are 32,768 compressed bytes, 262,144 decompressed bytes, 4,096 rows, 1,024 bytes per line, 128 bytes per field and 64 characters per decimal token. Decompression emits bounded chunks and rejects row/line/decompressed excess during inflation. One gzip member must terminate cleanly; CRC/ISIZE errors, truncation, concatenation and any trailing bytes fail closed. Decimal exponent and work/path bounds add separate guards. Safe descriptor-relative POSIX opening rejects symlink path components, devices/FIFOs and network-style path syntax; unsupported safe-open platforms fail closed. A regular path may still reside on an OS-mounted remote filesystem; locality is not established.

All six raw fields and score strings remain intact. No binary-float round trip, range normalization, guessed identity or second mter reversal occurs. The output has experimental review identity scoped to artifact, edition/task/system and source row, not a globally resolved model ID or independent experiment count. Row-level duplicate-report/revision/reused-judgment relationships remain unresolved, rather than being fabricated. Denominators, uncertainty, exact execution, first-publication and independent archival-capture times remain null with explicit status. Hardware and training budgets are not inferred or emitted.
