# Offline refresh fixture

These files are generated by `tests/test_refresh.py`. They are fictional pages for one invented person, Refresh Ada. They are not a production dataset and they are not a real person's belief.

- `dataset.json` is the first successful fetch.
- `dataset-changed.json` keeps the same statement slugs after the notes page text changes and an older page is inserted.
- `dataset-partial.json` is a separate collection that started on the changed notes page, so that page is version 1 there. It is not a successor file to `dataset-changed.json`.
- `manifest.json` records the slugs the import test follows.

Do not publish this directory with `scripts/deploy/publish-dataset.sh`.
